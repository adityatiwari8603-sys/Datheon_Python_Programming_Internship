
# Datheon Python Programming Internship

## Project Overview

This repository contains four Python projects developed as part of the Datheon Python Programming Internship.

Each project demonstrates practical Python programming concepts, including control flow, functions, file handling, data processing, regular expressions, and JSON.

## Completed Projects

### Task 1: Hangman Game

A terminal-based word-guessing game.

**Features:**

* Random word selection
* ASCII Hangman graphics
* Six incorrect guesses allowed
* Letter tracking and input validation
* Win/loss detection
* Replay functionality

**Main File:** `Task_1_Hangman/hangman.py`

### Task 2: Investment Portfolio Tracker

A command-line application for monitoring stock investments.

**Features:**

* Add stock investments
* Calculate invested amount and market value
* Calculate profit/loss and percentage returns
* Handle multiple stock entries
* Export portfolio summaries to CSV

**Main File:** `Task_2_Portfolio_Tracker/portfolio.py`

### Task 3: File Organizer

A Python application that automatically organizes files based on their extensions.

**Features:**

* Categorize documents, images, videos, audio, archives, and code
* Handle duplicate filenames
* Skip existing directories
* Display an organization summary
* Handle file access errors

**Main File:** `Task_3_File_Organizer/organizer.py`

### Task 4: Customer Support Chatbot

A rule-based chatbot that answers frequently asked customer questions.

**Features:**

* Greeting recognition
* Product and pricing information
* Shipping, returns, and refund responses
* Business hours and contact information
* Name recognition
* Fallback responses
* JSON-based FAQ configuration

**Main File:** `Task_4_Chatbot/chatbot.py`
